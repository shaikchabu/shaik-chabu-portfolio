# Shaik Chabu Portfolio

A ready-to-deploy, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — menu, reveal animations and year

## Deploy on Vercel
1. Create a GitHub repository, for example `shaik-chabu-portfolio`.
2. Upload these three files.
3. Import the repository into Vercel.
4. Deploy.
5. Vercel will provide a live URL such as `shaik-chabu-portfolio.vercel.app`.

## Before publishing
Replace `your-email@example.com` in `index.html` with your real email address.
Update any project links marked as placeholders.
Add your resume/certification links if desired.
